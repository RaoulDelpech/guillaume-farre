# Start Guillaume Farré

Tu démarres une session sur le projet Guillaume Farré (site artiste + boutique Fine Art).

## Étape 1: Lire règles métier et état projet

Lis ces fichiers dans cet ordre:

1. CLAUDE.md (règles métier complètes - tableaux vs photos, formats, pricing, Gelato)
2. ETAT_SESSION_2025-11-07_FINAL.md (état complet dernière session)
3. CORRECTIONS_URGENTES_2025-11-07.md (11 corrections prioritaires)
4. BONNES_PRATIQUES_DEV.md (tests, sécurité, accessibilité, signature Lalou)

## Étape 2: Vérifier état Git

Exécute:

```bash
git status
git log -3 --oneline
```

## Étape 3: Résumer en 5 lignes

Résume:
- État actuel projet (quelle phase de corrections)
- Dernière session (date + principales décisions)
- Prochaine tâche immédiate (quelle Phase démarrer)
- Fichiers modifiés non commités (si git status montre quelque chose)
- Alertes ou blocages potentiels

## Étape 4: Demander confirmation

Demande: "Prêt à démarrer sur [tâche identifiée] ?"

Attends "go" avant de commencer.

## MODE EDITION DES TEXTES

### Comment ca marche
1. Aller sur n'importe quelle page du site
2. Ajouter `?admin=true` a l'URL
   Exemple : `https://guillaumefarre.com/fr/histoire?admin=true`
3. Une barre jaune "Mode Edition" apparait en bas
4. Cliquer sur n'importe quel texte pour le modifier
5. Cliquer "Sauvegarder" pour enregistrer les modifications

### Important : Publication des modifications
Les modifications sont sauvegardees mais **ne s'affichent pas immediatement** sur le site.
Il faut cliquer sur le bouton **"Publier"** dans la barre d'edition pour que les changements soient visibles.
La publication prend environ 30 secondes.

## GUIDE DE LA PAGE ADMIN (Photos)

### 1. Connexion
- Aller sur https://guillaumefarre.com/fr/admin
- Entrer le mot de passe : `dino246`

### 2. Vue d'ensemble
La page admin permet de gerer toutes les photos du site :
- Voir toutes les photos
- Uploader de nouvelles photos
- Modifier les informations (titre, serie, categorie)
- Supprimer des photos
- Generer des descriptions avec l'IA

### 3. Uploader des photos

**Methode 1 - Glisser-deposer** :
- Glisser vos photos directement sur la zone de depot

**Methode 2 - Clic** :
- Cliquer sur "Choisir des fichiers"
- Selectionner vos photos

Les photos uploadees arrivent automatiquement dans la categorie "A trier".

### 4. Organiser les photos

**Filtres disponibles** :
- **Toutes** : Voir toutes les photos
- **A trier** : Photos nouvellement uploadees
- **Empreintes** : Photos de traces de pneu sur toile
- **Atelier** : Photos de la Dino et du lieu
- **Projection** : Photos de peinture projetee
- **Corbeille** : Photos supprimees (recuperables)

**Pour modifier une photo** :
1. Cliquer sur la photo
2. Un panneau s'ouvre avec les options :
   - Titre
   - Serie (empreintes, atelier, projection)
   - Description
   - Visible/Cache
3. Cliquer "Sauvegarder"

### 5. Supprimer une photo
1. Cliquer sur la photo
2. Cliquer "Supprimer"
3. La photo va dans la corbeille (recuperable)

Pour supprimer definitivement :
1. Aller dans le filtre "Corbeille"
2. Cliquer sur la photo
3. Cliquer "Supprimer definitivement"

### 6. Generer une description IA
1. Cliquer sur une photo
2. Cliquer "Generer description IA"
3. L'IA analyse l'image et propose un texte
4. Modifier si besoin
5. Sauvegarder

### 7. Actions en lot
Pour modifier plusieurs photos a la fois :
1. Cocher les photos souhaitees
2. Utiliser les boutons d'action en haut :
   - Changer la serie
   - Mettre en corbeille
   - Rendre visible/invisible

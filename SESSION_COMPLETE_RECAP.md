## ⌨️ Raccourcis Clavier Implémentés

### Globaux
- `Cmd+K` : Actions rapides
- `Cmd+S` : Sauvegarder
- `Cmd+B` : Toggle sidebar
- `Cmd+1-4` : Navigation onglets

### Photos
- `Cmd+A` : Tout sélectionner
- `Delete` : Supprimer sélection
- `Esc` : Désélectionner
- `G` : Toggle grille/liste

### Édition
- `Espace` : Comparer avant/après
- `Cmd+R` : Reset filtres
- `1/2/3` : Modes preview
- `G` : Grille composition

### Batch
- `Cmd+Shift+B` : Mode batch
- `P` : Publier
- `D` : Supprimer
- `T` : Tagger
- `E` : Exporter
